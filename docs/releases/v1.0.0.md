## Kimball Designer 1.0.0 — from first interview to bus matrix

The first release of a Claude skill and guided web UI for Kimball business-requirements gathering. It produces **bubble diagrams** (one per business process) and an **enterprise bus matrix**.

### Install

In Claude Code:

```text
/plugin marketplace add kristinnthor/Kimball-designer
/plugin install kimball-designer@kimball-designer
```

For Claude apps, download `kimball-designer-skill-1.0.0.zip` below and upload it under Settings → Capabilities → Skills. Other options are in [docs/INSTALL.md](https://github.com/kristinnthor/Kimball-designer/blob/main/docs/INSTALL.md).

### Highlights

- **Ten guided phases** in three stages: Discover (kickoff, stakeholders, requirements), Model (business processes, grain, dimensions, facts) and Deliver (bubble diagrams, bus matrix, review & export).
- **Claude skill** that coaches you phase by phase, asks at most three questions at a time, never invents business facts, validates against 16 Kimball rules and hands off a build-first recommendation.
- **Live sync**: `kimball serve` opens the UI on the same project file Claude edits, and changes flow both ways within seconds.
- **Deliverables**: requirements document, bus matrix (Markdown/CSV/HTML), bubble diagrams (SVG/PNG/Mermaid), all from one `*.kimball.json` file.
- **Offline and dependency-free**: the UI is a single HTML file and the CLI is a single `.mjs` file (Node 18+).
- **Examples**: retail, SaaS subscriptions and healthcare claims.
- **Quality**: over 100 unit tests, Playwright end-to-end tests (wizard, live sync, conflicts), and axe accessibility checks in light and dark themes.

### Known limitations

- The live-sync UI needs a local Node.js process, so in Claude apps the skill works in chat mode and with the offline UI.
- Detailed design (attribute-level dimension design, source-to-target mapping, DDL) is out of scope for 1.0. See the [roadmap](https://github.com/kristinnthor/Kimball-designer/blob/main/docs/ROADMAP.md).
