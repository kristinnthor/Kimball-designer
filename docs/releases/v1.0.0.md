## Kimball Designer 1.0.0 — from first interview to bus matrix

The first release of a Claude skill and guided web UI for Kimball business-requirements gathering. It produces **bubble diagrams** (one per business process) and an **enterprise bus matrix**, then lets you try the design as a star schema with sample data.

### Install

In Claude Code:

```text
/plugin marketplace add kristinnthor/Kimball-designer
/plugin install kimball-designer@kimball-designer
```

For Claude apps, download `kimball-designer-skill-1.0.0.zip` below and upload it under Settings → Capabilities → Skills. Or use the UI online at [kimball.kristinn.eu](https://kimball.kristinn.eu) without installing anything. Other options are in [docs/INSTALL.md](https://github.com/kristinnthor/Kimball-designer/blob/main/docs/INSTALL.md).

### Highlights

- **Eleven guided phases** in four stages: Discover (kickoff, stakeholders, requirements), Model (business processes, grain, dimensions, facts), Deliver (bubble diagrams, bus matrix, review & export) and Build (prototype).
- **Claude skill** that coaches you phase by phase, asks at most three questions at a time, never invents business facts, validates against 18 Kimball rules and recommends which process to build first.
- **Live sync**: `kimball serve` opens the UI on the same project file Claude edits, and changes flow both ways within seconds.
- **Deliverables**: requirements document, bus matrix (Markdown/CSV/HTML), bubble diagrams (SVG/PNG/Mermaid), all from one `*.kimball.json` file.
- **Prototype**: the design becomes a physical star schema with seeded sample data you can query in the browser. You get a CREATE TABLE script for PostgreSQL, SQL Server or Snowflake with index recommendations, a Docker sandbox, CSVs and a dbt project with tests (dbt 1.10.8 or later). Save the query that answers each requirement, and the requirements document shows which ones the design answers.
- **Help and demos**: a Help page with guided demos, a guide to every deliverable, a glossary and an FAQ, also as [docs/USER-GUIDE.md](https://github.com/kristinnthor/Kimball-designer/blob/main/docs/USER-GUIDE.md).
- **Offline and dependency-free**: the UI is a single HTML file and the CLI is a single `.mjs` file (Node 18+).
- **Examples**: retail, SaaS subscriptions and healthcare claims.
- **Quality**: more than 200 unit tests, including the generated SQL and dbt models run on PostgreSQL; Playwright end-to-end tests (wizard, live sync, conflicts, prototype, phone layout); and axe accessibility checks in light and dark themes.

### Known limitations

- The live-sync UI needs a local Node.js process, so in Claude apps the skill works in chat mode and with the offline or online UI.
- The prototype reads sample data. Source-to-target mappings and load (ETL/ELT) code are not generated: connect your own staging models to the dbt project. See the [roadmap](https://github.com/kristinnthor/Kimball-designer/blob/main/docs/ROADMAP.md).
